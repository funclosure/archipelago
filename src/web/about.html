Archipelago
How it works Ways to use it Open the map

Chart what you understand about a subject, as islands on a map.

Say what you want to learn and why. A cartographer sketches the subject as islands, each with a few landmarks that matter. Sail to one and talk: the Mentor teaches, the Keeper asks you to explain it and marks how solid your answers are. Open water is what you have not charted yet.

Try it in your browser Use it in Claude Code

How it works

  1. Sketch

    Describe a subject in your own words. The cartographer proposes islands, the straits between them, and seas that group them. Nothing lands on the map until you approve it.

  2. Explore

    On each island the Mentor explains with analogies from what you already know, draws diagrams, writes code, and builds small demos you can try. Pin what you want to keep to the island's board.

  3. Chart

    The Keeper asks you to explain an island in your own words. It lights a landmark when you show it, and marks the island when it has heard enough.

What the map shows

  • Open water: not charted yet. Never a score.
  • Sandbar: some of it holds, not yet all.
  • Settled: you can explain it.
  • Mountainous: you can explain it and build on it.
  • Reef: a confident belief that turned out wrong, written only when you agree.

Ways to use it

In your browser

Nothing to install. Bring a key from Claude, Gemini, or OpenRouter, or try it first without one. Your key stays in your browser and goes only to that provider; your charts stay in your browser too.

Open Archipelago

In Claude Code

Claude Code becomes your cartographer in the terminal, and the map opens on your machine. The Keeper and the Mentor run on your Claude Code login, so there is no key to bring.

Needs Bun. Then, in Claude Code:

/plugin marketplace add funclosure/archipelago
/plugin install archipelago@archipelago

Then ask Claude to chart something:

Chart system design with Archipelago.

From your shell instead: claude plugin marketplace add funclosure/archipelago && claude plugin install archipelago@archipelago

From source

Clone the repository and link the command. MIT licensed.

git clone https://github.com/funclosure/archipelago
cd archipelago
bun install && bun link
archipelago serve

Your charts are yours

In the browser they live in that browser; download a backup from the domain menu. In the terminal they are one SQLite file at ~/.archipelago/archipelago.sqlite. A backup from either opens in the other.
