Share a map of your own

The gallery is a folder of files in the open-source repository, and a map joins it by pull request.

  1. Chart a domain in Archipelago, or have another AI write one: New domain, then Import a map, has a prompt to copy.
  2. Choose Export this map in the domain menu. The file holds the structure only: its islands, landmarks, straits and seas. Nothing you said is in it, and no verdict.
  3. Add a line saying who made it, "by": "Your name", and name the file <slug>.archipelago.json.
  4. Open a pull request that adds it to src/web/gallery. The README there says how to check it first.

What a shared map needs

  • Six to twelve islands, each with a one-line summary and three to eight landmarks: the ideas someone must be able to explain to say they understand it.
  • Two to four seas, with every island in exactly one.
  • Accurate, and your own work. A map is read by people who do not yet know the subject.
  • English or Traditional Chinese. A translation is a second file with the same slugs.
  • Shared under the MIT License, like the rest of the repository, so anyone may use and change it.
