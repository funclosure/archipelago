# Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-island whiteboard of cards (diagram, note, code) that the Keeper pins through a new tool and reads as context, and that the reader edits on a layer over the map area, toggled by a button and the key `b`.

**Architecture:** One new table (`board_cards`, migration 0007) behind `boardRepository.ts`. One tool function `boardWrite(deps, input, author)` in `tools.ts` carries the rules for both sides: the SDK tool calls it as `judge`, the route `POST /api/board` calls it as `you`. The judge context gains a `Board` section. On the page, `board-model.js` is pure (editor state, POST body, cursor) and `board.js` owns the `#board` layer, the toggle button, the editor with a live preview, and the board's key handler, which the map region hands its keys to while the board is open.

**Tech Stack:** Bun, `bun:sqlite`, zod 4, the Claude Agent SDK tool surface, plain ES modules on the page, mermaid (already served), shiki (already served), `bun test`.

**Spec:** `docs/superpowers/specs/2026-09-06-board-design.md`

## Global Constraints

- Tests run with `bun test` only (never vitest). Typecheck with `bunx tsc --noEmit`. Run both before every commit.
- The page has no framework, no bundler, no `innerHTML`. Every DOM node is built with `createElement`/`textContent`/`append`/`replaceChildren`.
- Schema changes go in a new numbered migration; `0001_initial.sql` is frozen. Every write bumps `view_state.version` through SQL triggers. Columns are snake_case, aliased to camelCase in every `select`.
- Open water is the absence of a verdict; never store or render an "open" state.
- The judge writes only through its tools, closed by `tools: []` plus `allowedTools` in `src/server/judge/sdk.ts`; do not "fix" it back to `canUseTool`.
- `bun test` never spawns the SDK: server tests run with `stub: true`.
- Card authors are the message roles, exactly `you` and `judge`. The page's strings say "the Keeper"; PROTOCOL and code say judge.
- Card kinds are exactly `diagram`, `note`, `code`. `lang` is kept only on code cards; a code card's `lang` is one of `swift`, `objective-c`, `kotlin`, `typescript`, `tsx`, `javascript`, `json`, `bash`, `python`, `sql`, `yaml`, or null for plain text.
- The Keeper may update or remove only cards whose author is `judge`; the reader may edit or remove any card. A card keeps the author who created it.
- A `judge` write adds exactly one `system` message to the thread: `board: pinned "<title>"`, `board: updated "<title>"`, or `board: removed "<title>"`. A `you` write adds no message. Board writes never start a judge turn.
- Board layer geometry: `top: 0; bottom: 0; left: var(--outline-w); right: 0`, `right: var(--pane-w)` when `body.pane-open`; z-index 2 (above the chrome and `.cta`, below `.map-focus` at 3 and `.keys` at 6). Toggle button `right: 16px; bottom: 16px`, `right: calc(var(--pane-w) + 16px)` when the pane is open. Preview debounce 500 ms. Card column max width 760px.
- Board keys (map region, board open): `j`/`↓`, `k`/`↑`, `Home`, `End` move the cursor; `Enter` edits; `d`/`n`/`c` add a diagram/note/code card; `x` removes the card under the cursor; `⌘↵` saves the editor; `b` (global) toggles the board. Escape rungs, in order: sheet, menu, blur, editor, board, cursor, deselect.
- Commit messages end with the trailers:
  ```
  Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01CRzNtnhqVcygozGdKkfExq
  ```

```sql
-- Board cards: the island's whiteboard. Both sides write; creation order is the order.
create table board_cards (
  id integer primary key autoincrement,
  domain_id integer not null references domains(id) on delete cascade,
  island_id integer not null references islands(id) on delete cascade,
  kind text not null check (kind in ('diagram', 'note', 'code')),
  title text not null,
  body text not null,
  lang text,
  author text not null check (author in ('you', 'judge')),
  created_at text not null default (strftime('%Y-%m-%dT%H:%M:%fZ', 'now')),
  updated_at text not null default (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
);
create index board_cards_island on board_cards(island_id, id);
create trigger board_cards_ai after insert on board_cards begin
  update view_state set version = version + 1 where domain_id = new.domain_id;
end;
create trigger board_cards_au after update on board_cards begin
  update view_state set version = version + 1 where domain_id = new.domain_id;
end;
create trigger board_cards_ad after delete on board_cards begin
  update view_state set version = version + 1 where domain_id = old.domain_id;
end;
```

```ts
import type { Database } from "bun:sqlite";
import { NotFoundError } from "../errors.ts";
import type { BoardCard, BoardKind, MessageRole } from "../types.ts";

const COLS = "id, domain_id as domainId, island_id as islandId, kind, title, body, lang, author, created_at as createdAt, updated_at as updatedAt";
const NOW = "strftime('%Y-%m-%dT%H:%M:%fZ','now')";

export type CardInsert = { domainId: number; islandId: number; kind: BoardKind; title: string; body: string; lang?: string | null; author: MessageRole };
export type CardPatch = { title?: string; body?: string; lang?: string | null };

export function addCard(db: Database, input: CardInsert): BoardCard {
  return db
    .query<BoardCard, Record<string, string | number | null>>(
      `insert into board_cards (domain_id, island_id, kind, title, body, lang, author)
       values ($domainId, $islandId, $kind, $title, $body, $lang, $author) returning ${COLS}`,
    )
    .get({ $domainId: input.domainId, $islandId: input.islandId, $kind: input.kind, $title: input.title, $body: input.body, $lang: input.lang ?? null, $author: input.author })!;
}

export function getCard(db: Database, id: number): BoardCard | null {
  return db.query<BoardCard, [number]>(`select ${COLS} from board_cards where id = ?`).get(id) ?? null;
}

/** The card, if it is on this island; a card elsewhere is not found here. */
export function requireCard(db: Database, islandId: number, id: number): BoardCard {
  const card = getCard(db, id);
  if (!card || card.islandId !== islandId) throw new NotFoundError(`no card ${id} on this island`);
  return card;
}

export function listCards(db: Database, islandId: number): BoardCard[] {
  return db.query<BoardCard, [number]>(`select ${COLS} from board_cards where island_id = ? order by id`).all(islandId);
}

/** Applies the given fields and stamps updated_at. Fields left out keep their value; the author never changes. */
export function updateCard(db: Database, id: number, patch: CardPatch): BoardCard {
  const current = getCard(db, id);
  if (!current) throw new NotFoundError(`no card ${id}`);
  return db
    .query<BoardCard, Record<string, string | number | null>>(
      `update board_cards set title = $title, body = $body, lang = $lang, updated_at = ${NOW} where id = $id returning ${COLS}`,
    )
    .get({
      $id: id,
      $title: patch.title ?? current.title,
      $body: patch.body ?? current.body,
      $lang: patch.lang === undefined ? current.lang : patch.lang,
    })!;
}

export function removeCard(db: Database, id: number): BoardCard {
  const row = db.query<BoardCard, [number]>(`delete from board_cards where id = ? returning ${COLS}`).get(id);
  if (!row) throw new NotFoundError(`no card ${id}`);
  return row;
}
```

```ts
const cardTitle = z
  .string()
  .trim()
  .min(1)
  .refine((t) => !/\n/.test(t), { message: "a title is one line" });
/** Not trimmed: code and diagrams keep their whitespace. */
const cardBody = z.string().refine((b) => b.trim().length > 0, { message: "a body cannot be empty" });
const cardLang = z.string().trim().min(1).nullable().optional();

const boardAdd = z.object({ op: z.literal("add"), kind: z.enum(boardKinds), title: cardTitle, body: cardBody, lang: cardLang });
const boardUpdate = z.object({ op: z.literal("update"), id: cardId, title: cardTitle.optional(), body: cardBody.optional(), lang: cardLang });
const boardRemove = z.object({ op: z.literal("remove"), id: cardId });
const needsAField = (v: { op: string; title?: string; body?: string; lang?: string | null }) =>
  v.op !== "update" || v.title !== undefined || v.body !== undefined || v.lang !== undefined;
const NEEDS_A_FIELD = { message: "an update needs a title, a body, or a lang" };

/** What the judge's board_write tool and the reader's POST /api/board both accept. */
export const boardWriteInputSchema = z.discriminatedUnion("op", [boardAdd, boardUpdate, boardRemove]).refine(needsAField, NEEDS_A_FIELD);
export type BoardWriteInput = z.infer<typeof boardWriteInputSchema>;

const boardScope = { domain: slugSchema, island: slugSchema };
export const boardPostInputSchema = z
  .discriminatedUnion("op", [boardAdd.extend(boardScope), boardUpdate.extend(boardScope), boardRemove.extend(boardScope)])
```

```ts
export type BoardWriteResult = { card: BoardCard } | { removed: number; title: string };

/**
 * Adds, updates, or removes a card on this island's board. The SDK tool calls it as the judge, the route as the reader.
 * The judge may only update or remove its own cards and leaves one system line per write; the reader may edit any card and leaves none.
 */
export function boardWrite(deps: ToolDeps, input: unknown, author: MessageRole = "judge"): BoardWriteResult {
  const parsed = boardWriteInputSchema.parse(input);
  return withDb(deps.dbPath, (db) =>
    db.transaction((): BoardWriteResult => {
      const domain = requireDomain(db, deps.domain);
      const island = requireIsland(db, domain.id, deps.island);
      const line = (verb: string, title: string) => {
        if (author !== "judge") return;
        addMessage(db, { domainId: domain.id, islandId: island.id, role: "judge", kind: "system", body: `board: ${verb} "${title}"` });
      };
      if (parsed.op === "add") {
        const card = addCard(db, {
          domainId: domain.id, islandId: island.id, kind: parsed.kind, title: parsed.title, body: parsed.body,
          lang: parsed.kind === "code" ? parsed.lang ?? null : null, author,
        });
        line("pinned", card.title);
        return { card };
      }
      const existing = requireCard(db, island.id, parsed.id);
      if (author === "judge" && existing.author !== "judge") {
        throw new ArchipelagoError(`the reader wrote card ${existing.id}; add your own card instead`);
      }
      if (parsed.op === "remove") {
        removeCard(db, existing.id);
        line("removed", existing.title);
        return { removed: existing.id, title: existing.title };
      }
      const card = updateCard(db, existing.id, { title: parsed.title, body: parsed.body, lang: existing.kind === "code" ? parsed.lang : null });
      line("updated", card.title);
      return { card };
    })(),
  );
}
```

```ts
      lines.push(`- #${c.id} ${c.kind}${c.lang ? ` (${c.lang})` : ""} "${indent(c.title)}" [${marks.join(", ")}]:`, `  ${indent(c.body)}`);
    }
  }
```

```js
// Pure, DOM-free: the board's editor state, the POST body it becomes, and the keyboard cursor over cards.

export const CARD_KINDS = ["diagram", "note", "code"];
/** The key that adds each kind while the board is open. */
export const KIND_KEYS = { d: "diagram", n: "note", c: "code" };
const DEFAULT_LANG = "swift";
/** The language select's value for a code card with no language. */
export const PLAIN = "plain";

/** A fresh editor for a new card of `kind`. Code cards start in Swift; other kinds carry no lang. */
export function startAdd(kind) {
  return { id: null, kind, title: "", body: "", lang: kind === "code" ? DEFAULT_LANG : null };
}

/** An editor over an existing card. */
export function startEdit(card) {
  return { id: card.id, kind: card.kind, title: card.title, body: card.body, lang: card.kind === "code" ? card.lang ?? PLAIN : null };
}

/** A card needs a title and a body. */
export function canSave(editor) {
  return editor.title.trim().length > 0 && editor.body.trim().length > 0;
}

/** The write for POST /api/board (without domain and island). lang travels only for code; plain becomes null. */
export function writeOf(editor) {
  const base = { title: editor.title.trim(), body: editor.body };
  if (editor.kind === "code") base.lang = editor.lang === PLAIN ? null : editor.lang;
  return editor.id === null ? { op: "add", kind: editor.kind, ...base } : { op: "update", id: editor.id, ...base };
}

/** The card id the cursor moves to on `key`, or null when it stays. */
export function moveCard(ids, cursor, key) {
  if (ids.length === 0) return null;
  const down = key === "ArrowDown" || key === "j";
  const up = key === "ArrowUp" || key === "k";
  const i = ids.indexOf(cursor);
  if (i < 0) {
    if (down || up || key === "Home") return ids[0];
    return key === "End" ? ids[ids.length - 1] : null;
  }
  if (down) return i + 1 < ids.length ? ids[i + 1] : null;
  if (up) return i > 0 ? ids[i - 1] : null;
  if (key === "Home") return ids[0];
  if (key === "End") return ids[ids.length - 1];
  return null;
}

/** The cursor after the list changed: the same id if its card is still there, else null. */
export function keepCursor(ids, cursor) {
  return cursor !== null && ids.includes(cursor) ? cursor : null;
}
```

```js
/** A closed mermaid fence: rendered once per source and cached, with the source as the fallback. `cache: false` for a live preview. */
export function diagramElement(source, { cache = true } = {}) {
  const box = document.createElement("div");
  box.className = "diagram";
  const cap = document.createElement("div");
  cap.className = "cap";
  cap.textContent = "diagram";
  box.append(cap);
  const holder = document.createElement("div");
  box.append(holder);
  if (cache && nodeCache.has(source)) {
    holder.append(nodeCache.get(source).cloneNode(true));
    return box;
  }
  if (!mermaidInit()) {
    holder.append(sourceBlock(source));
    return box;
  }
  holder.textContent = "drawing a diagram…";
  let p = cache ? pending.get(source) : undefined;
  if (!p) {
    p = window.mermaid
      .render(`diagram-${++diagramSeq}`, source)
      .then(({ svg }) => {
        pending.delete(source);
        return svg;
      })
      .catch((e) => {
        pending.delete(source);
        throw e;
      });
    if (cache) pending.set(source, p);
  }
  p.then((svg) => {
    const node = svgNode(svg);
    if (!node) {
      holder.replaceChildren(sourceBlock(source));
      return;
    }
    if (cache) nodeCache.set(source, node);
    holder.replaceChildren(node);
  }).catch(() => holder.replaceChildren(sourceBlock(source)));
  return box;
}
```

```js
// The board: the island's whiteboard over the map area. Cards both sides write. board-model.js holds the pure parts;
// this module owns #board, #board-toggle, the editor with its live preview, and the board's key handler.
import { app, api } from "./app.js";
import { renderMarkdown, diagramElement } from "./markdown.js";
import { codeElement } from "./code.js";
import { LANGS } from "./code-model.js";
import { registerRegion, setRegion } from "./keys.js";
import { startAdd, startEdit, canSave, writeOf, moveCard, keepCursor, KIND_KEYS, PLAIN } from "./board-model.js";

const PREVIEW_MS = 500;
const board = document.getElementById("board");
const toggle = document.getElementById("board-toggle");

const state = {
  slug: null,       // the island the cards belong to
  cards: [],
  loaded: false,
  version: null,    // snapshot version the cards were fetched at; null forces a refetch
  open: false,
  editor: null,     // see startAdd / startEdit in board-model.js
  cursor: null,     // card id under the keyboard cursor
  saving: false,
  loadError: null,
};
let loadGen = 0;
let previewTimer = 0;
let previewSeq = 0;
let editorNode = null;   // the editor element, kept across renders so typing is never interrupted
let editorFor = null;    // the state.editor object editorNode was built for
let editorStatus = null; // the status span inside editorNode
let editorFocus = null;  // focuses the right field of the open editor

export function boardOpen() {
  return state.open && Boolean(state.slug);
}

function el(tag, className, text) {
  const e = document.createElement(tag);
  if (className) e.className = className;
  if (text !== undefined) e.textContent = text;
  return e;
}

function button(label, onClick, className = "") {
  const b = el("button", className, label);
  b.type = "button";
  b.addEventListener("click", onClick);
  return b;
}

const post = (write) =>
  api("/api/board", {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ domain: app.domain, island: state.slug, ...write }),
  });

async function load(slug) {
  const gen = ++loadGen;
  const version = app.version;
  try {
    const { cards } = await api(`/api/board?domain=${encodeURIComponent(app.domain)}&island=${encodeURIComponent(slug)}`);
    if (gen !== loadGen || state.slug !== slug) return;
    state.cards = cards;
    state.loaded = true;
    state.loadError = null;
    state.version = version;
    state.cursor = keepCursor(cards.map((c) => c.id), state.cursor);
  } catch (error) {
    if (gen !== loadGen) return;
    state.loadError = error.message;
  }
  render();
}

/** Runs on every snapshot and selection change: follows the selected island and refetches when the version moved. */
function sync() {
  const slug = app.selected;
  if (slug !== state.slug) {
    state.slug = slug;
    state.cards = [];
    state.loaded = false;
    state.cursor = null;
    state.editor = null;
    state.version = null;
    if (!slug) state.open = false;
  }
  if (slug && state.version !== app.version) void load(slug);
  render();
}

function setOpen(open) {
  if (open && !state.slug) return;
  state.open = open;
  if (!open) state.editor = null;
  render();
  setRegion("map"); // the board lives in the map's slot; keys.js resolves the map container to #board while it is open
}

function add(kind) {
  state.editor = startAdd(kind);
  render();
  editorFocus?.();
}

function edit(card) {
  state.editor = startEdit(card);
  state.cursor = card.id;
  render();
  editorFocus?.();
}

function cancelEditor() {
  if (!state.editor) return false;
  state.editor = null;
  render();
  board.focus({ preventScroll: true });
  return true;
}

async function saveEditor() {
  const ed = state.editor;
  if (!ed || !canSave(ed) || state.saving) return false;
  state.saving = true;
  setStatus("saving…");
  try {
    const result = await post(writeOf(ed));
    state.saving = false;
    if (state.editor !== ed) return true; // cancelled or replaced while saving
    state.editor = null;
    state.cursor = result.card.id;
    await load(state.slug);
    board.focus({ preventScroll: true });
  } catch (error) {
    state.saving = false;
    setStatus(error.message, true);
  }
  return true;
}

async function remove(id) {
  try {
    await post({ op: "remove", id });
    if (state.editor && state.editor.id === id) state.editor = null;
    await load(state.slug);
  } catch (error) {
    state.loadError = error.message;
    render();
  }
}

function setStatus(text, bad = false) {
  if (!editorStatus) return;
  editorStatus.textContent = text;
  editorStatus.classList.toggle("bad", bad);
}

function paintCursor() {
  for (const c of board.querySelectorAll(".card")) c.classList.toggle("cur", Number(c.dataset.id) === state.cursor);
}

function scrollCursorIntoView() {
  board.querySelector(".card.cur")?.scrollIntoView({ block: "nearest" });
}

function bodyEl(kind, body, lang, { cache = true } = {}) {
  if (kind === "diagram") return diagramElement(body, { cache });
  if (kind === "code") return codeElement(lang ?? "text", body, true);
  const div = el("div", "note");
  div.append(renderMarkdown(body));
  return div;
}

function cardEl(card) {
  const box = el("article", `card${card.id === state.cursor ? " cur" : ""}`);
  box.dataset.id = String(card.id);
  const cap = el("div", "cap");
  cap.append(
    el("span", "kind", card.kind + (card.lang ? ` · ${card.lang}` : "")),
    el("span", "title", card.title),
    el("span", "who", card.author === "judge" ? "the Keeper" : "you"),
  );
  const acts = el("span", "acts");
  acts.append(button("edit", () => edit(card)), button("remove", () => void remove(card.id)));
  cap.append(acts);
  box.append(cap, bodyEl(card.kind, card.body, card.lang));
  box.addEventListener("mousedown", () => {
    state.cursor = card.id;
    paintCursor();
  });
  return box;
}

const PLACEHOLDER = {
  diagram: "flowchart TB\n  app[App] --> cache[Cache]\n  cache --> db[(Database)]",
  note: "A claim, a definition, a list: markdown.",
  code: "Three to twelve lines is plenty.",
};

function renderPreview(ed, preview, err) {
  const seq = ++previewSeq;
  err.hidden = true;
  if (!ed.body.trim()) {
    preview.replaceChildren(el("div", "empty", "preview"));
    return;
  }
  if (ed.kind === "diagram" && window.mermaid) {
    window.mermaid
      .parse(ed.body)
      .then(() => {
        if (seq !== previewSeq || state.editor !== ed) return;
        preview.replaceChildren(bodyEl("diagram", ed.body, null, { cache: false }));
      })
      .catch((e) => {
        if (seq !== previewSeq || state.editor !== ed) return;
        err.textContent = String(e && e.message ? e.message : e).split("\n").slice(0, 3).join("\n");
        err.hidden = false; // the last good render stays in the preview
      });
    return;
  }
  preview.replaceChildren(bodyEl(ed.kind, ed.body, ed.lang === PLAIN ? null : ed.lang, { cache: false }));
}

function editorEl(ed) {
  const box = el("div", "editor");
  const fields = el("div", "fields");
  const title = document.createElement("input");
  title.type = "text";
  title.className = "title";
  title.placeholder = "title";
  title.value = ed.title;
  title.dataset.field = "title";
  fields.append(title);
  let lang = null;
  if (ed.kind === "code") {
    lang = document.createElement("select");
    lang.dataset.field = "lang";
    for (const l of [...LANGS, PLAIN]) {
      const o = document.createElement("option");
      o.value = l;
      o.textContent = l;
      o.selected = l === ed.lang;
      lang.append(o);
    }
    fields.append(lang);
  }
  const ta = document.createElement("textarea");
  ta.value = ed.body;
  ta.placeholder = PLACEHOLDER[ed.kind];
  ta.spellcheck = false;
  ta.dataset.field = "body";
  const err = el("div", "err");
  err.hidden = true;
  fields.append(ta, err);
  const preview = el("div", "preview");
  const row = el("div", "row");
  const save = button("save", () => void saveEditor(), "primary");
  row.append(save, button("cancel", cancelEditor));
  if (ed.id !== null) row.append(button("remove", () => void remove(ed.id), "danger"));
  const status = el("span", "status");
  row.append(status);
  box.append(fields, preview, row);

  const updateSave = () => {
    save.disabled = !canSave(ed) || state.saving;
  };
  const schedulePreview = () => {
    clearTimeout(previewTimer);
    previewTimer = setTimeout(() => renderPreview(ed, preview, err), PREVIEW_MS);
  };
  title.addEventListener("input", () => {
    ed.title = title.value;
    updateSave();
  });
  lang?.addEventListener("change", () => {
    ed.lang = lang.value;
    schedulePreview();
  });
  ta.addEventListener("input", () => {
    ed.body = ta.value;
    updateSave();
    schedulePreview();
  });
  updateSave();
  renderPreview(ed, preview, err);
  editorStatus = status;
  editorFocus = () => (ed.title ? ta : title).focus();
  return box;
}

/** The editor element for the current editor, built once per editor session. */
function currentEditor() {
  if (editorFor !== state.editor || !editorNode) {
    editorNode = editorEl(state.editor);
    editorFor = state.editor;
  }
  return editorNode;
}

function headEl(island) {
  const head = el("div", "head");
  head.append(el("span", "name", island.name), el("span", "count", `${state.cards.length} ${state.cards.length === 1 ? "card" : "cards"}`), el("span", "spacer"));
  head.append(button("+ diagram", () => add("diagram")), button("+ note", () => add("note")), button("+ code", () => add("code")), button("map", () => setOpen(false)));
  return head;
}

function columnEl() {
  const col = el("div", "column");
  if (state.loadError) col.append(el("div", "err-line", state.loadError));
  if (state.editor && state.editor.id === null) col.append(currentEditor());
  if (state.loaded && state.cards.length === 0 && !state.editor) {
    col.append(el("div", "empty", "Nothing pinned yet. The Keeper pins what you keep pointing at; you can add a diagram, a note, or code."));
  }
  for (const card of state.cards) col.append(state.editor && state.editor.id === card.id ? currentEditor() : cardEl(card));
  return col;
}

function render() {
  const island = app.snapshot && state.slug ? app.snapshot.islands.find((i) => i.slug === state.slug) ?? null : null;
  toggle.hidden = !island || state.open;
  if (island) toggle.replaceChildren(el("span", null, `board · ${state.cards.length}`), el("kbd", null, "b"));
  const show = Boolean(island) && state.open;
  if (!show) {
    board.hidden = true;
    board.replaceChildren();
    editorNode = null;
    editorFor = null;
    return;
  }
  const active = document.activeElement;
  const keep = editorNode && editorNode.contains(active) ? active : null;
  const scrollTop = board.querySelector(".column")?.scrollTop ?? 0;
  board.hidden = false;
  board.replaceChildren(headEl(island), columnEl());
  if (!state.editor) {
    editorNode = null;
    editorFor = null;
    editorStatus = null;
  }
  board.querySelector(".column").scrollTop = scrollTop;
  if (keep && keep.isConnected) keep.focus({ preventScroll: true });
}

export function installBoard() {
  app.listeners.add(sync);
  toggle.addEventListener("click", () => setOpen(true));
  registerRegion("board", {
    isOpen: () => boardOpen(),
    editing: () => Boolean(state.editor),
    toggle: () => setOpen(!state.open),
    close: () => setOpen(false),
    cancelEditor,
    save: () => (state.editor ? (void saveEditor(), true) : false),
    onKey(e) {
      if (state.editor) return false; // the fields own their keys; Escape and ⌘↵ are handled by keys.js
      const moved = moveCard(state.cards.map((c) => c.id), state.cursor, e.key);
      if (moved !== null) {
        state.cursor = moved;
        paintCursor();
        scrollCursorIntoView();
        return true;
      }
      if (Object.hasOwn(KIND_KEYS, e.key)) {
        add(KIND_KEYS[e.key]);
        return true;
      }
      switch (e.key) {
        case "Enter": {
          const card = state.cards.find((c) => c.id === state.cursor);
          if (!card) return false;
          edit(card);
          return true;
        }
        case "x":
          if (state.cursor === null) return false;
          void remove(state.cursor);
          return true;
        default:
          return false;
      }
    },
  });
  render();
}
```
