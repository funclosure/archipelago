# Harbour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the cartographer mark one island per scale as the harbour, the place to set out from, and show it on the map, in the strip, and in the pane.

**Architecture:** A `harbour` flag on `islands` (migration 0005, one per parent by partial unique index) with three repository functions; the snapshot carries `harbour` per island and per scale; a `harbour` CLI verb; the page draws an anchor beside the name, leads the strip with `Set out from` / `Home port`, and adds a pill in the pane head. The judge is untouched. Spec: `docs/superpowers/specs/2026-09-04-harbour-design.md`.

**Tech Stack:** Bun, `bun:sqlite`, commander, zod, plain ES-module canvas page. Tests with `bun test` only.

## Global Constraints

- `bun test`, never vitest; `bunx tsc --noEmit` clean. Migrations `0001`–`0004` are frozen; schema changes go in `src/core/migrations/0005_harbour.sql`.
- snake_case columns aliased to camelCase in every `select` (`COLS` in the island repository).
- At most one harbour per parent per domain, enforced by `create unique index islands_harbour_per_parent on islands(domain_id, coalesce(parent_id, 0)) where harbour = 1`.
- `Island.harbour` is `0 | 1` (SQLite integer); `IslandView.harbour` is `boolean`; `Snapshot.harbour` is `string | null` (slug at the current scale).
- Every write bumps `view_state.version` (the existing `islands_au` trigger covers it).
- CLI: JSON always; errors exit 1 with `{ error, valid? }`. `harbour set` prints `{ harbour, parent, version }`; `clear` prints `{ cleared, version }`; `show` prints `{ harbour, parent }`; `--parent` omitted means the top scale; `set` on the current harbour is idempotent.
- Copy, verbatim: strip labels `Set out from` (harbour has no verdict) and `Home port` (it has one); pane pill `harbour`; anchor glyph `⚓` in the label font, sand colour, 6px left of the name.
- Page: no framework, no bundler, no `innerHTML`.

```ts
/** Marks `slug` as the harbour among its siblings, clearing whichever sibling had it. Idempotent. */
export function setHarbour(db: Database, domainId: number, slug: string): Island {
  const island = requireIsland(db, domainId, slug);
  return db.transaction(() => {
    clearHarbour(db, domainId, island.parentId);
    return db
      .query<Island, [number]>(`update islands set harbour = 1, updated_at = ${NOW} where id = ? returning ${COLS}`)
      .get(island.id)!;
  })();
}

/** Clears the harbour among one parent's children (null = the top scale). Returns how many rows changed. */
export function clearHarbour(db: Database, domainId: number, parentId: number | null): number {
  const result =
    parentId === null
      ? db.run(`update islands set harbour = 0, updated_at = ${NOW} where domain_id = ? and parent_id is null and harbour = 1`, [domainId])
      : db.run(`update islands set harbour = 0, updated_at = ${NOW} where domain_id = ? and parent_id = ? and harbour = 1`, [domainId, parentId]);
  return Number(result.changes);
}

/** The harbour among one parent's children (null = the top scale), or null. */
export function getHarbour(db: Database, domainId: number, parentId: number | null): Island | null {
  if (parentId === null) {
    return db.query<Island, [number]>(`select ${COLS} from islands where domain_id = ? and parent_id is null and harbour = 1`).get(domainId) ?? null;
  }
  return db.query<Island, [number, number]>(`select ${COLS} from islands where domain_id = ? and parent_id = ? and harbour = 1`).get(domainId, parentId) ?? null;
}
```

`updateIsland`'s `update … returning ${COLS}` and `upsertIsland` need no change: the column has a default and `COLS` now returns it.

```js
function drawLabel(ctx, node, grow, hasOwnVerdict) {
  ctx.font = LABEL_FONT;
  ctx.textAlign = "center";
  ctx.textBaseline = "top";
  ctx.fillStyle = node.state === "open" ? PALETTE.openText : PALETTE.text;
  const offset = !hasOwnVerdict && node.island.children.total > 0 ? 30 : 14;
  const y = node.y + node.radius * grow + offset;
  ctx.fillText(node.name, node.x, y);
  if (node.island.harbour) {
    // The harbour: an anchor hangs off the left edge of the name; the name stays centred on the island.
    const half = ctx.measureText(node.name).width / 2;
    ctx.textAlign = "right";
    ctx.fillStyle = PALETTE.sand;
    ctx.fillText("⚓", node.x - half - ANCHOR_GAP, y);
  }
}
```
